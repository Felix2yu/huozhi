# 统一全站页面样式

## 目标
所有认证内页面（13 个）采用统一的页面骨架：**PageHeader（标题+操作）→ HeroCard（渐变汇总大卡，每页都有）→ 内容区**，消除 4 种页头写法、6 种渐变、3 套 Tab 的碎片化。移动端顶栏（Logo+页面标题+汉堡）保持现状不动，页内标题仅在桌面端显示，避免移动端标题重复。

## 一、新增共享组件（`frontend/src/components/common/`）

1. **`PageHeader`**：`{ title, subtitle?, actions?, back? }`
   - 标题/副标题 `hidden md:block`（桌面显示，移动端由顶栏顶栏标题承担）；`actions` 与 `back` 所有断点可见（如"新增账户"、记一笔的返回按钮）
   - 统一 `mb-*` 间距，不再各页自写 `<h1>`/`<header>`
2. **`HeroCard`**：统一渐变大卡（brand→emerald 渐变 + 装饰 blur，一套实现）；props：`{ tone?: 'brand' | 'warning' }`（warning 红渐变仅用于预算超支等语义警示）；内容用统一插槽：左侧说明文字 + 右侧/下方统计数字
3. **`SegmentedTabs`**：统一分段 Tab（沿用现分类页的 `card p-1.5` 圆角块风格），替换分类页、记一笔类型切换、统计页时间范围三处各自实现
4. 页面容器统一：去掉各页自己的 `max-w-6xl`/`max-w-4xl` 等，统一依赖 AppLayout main 的 `max-w-[1400px]` + `px-4 md:px-8`，纵向间距统一 `space-y-5 md:space-y-6`

## 三、顺带清理
- 重复/零散按钮样式（如 AppLayout 离线徽标手写 amber 类）尽量归到 `.btn-*` 语义类
- 新组件统一使用 CSS 变量/现有 token（brand、`--income/--expense`），暗色模式沿用现有机制
- 登录/注册页不在 AppLayout 内、为独立宣传布局，本轮不动

## 四、验证
- `npm run build` + `npm test`（Vitest）
- 启动 dev server，用浏览器逐页检查浅色/暗色 × 桌面/移动宽度：标题不重复、hero 每页都有、Tab/按钮一致
- 不改后端、不改业务逻辑与数据流，只动展示层
